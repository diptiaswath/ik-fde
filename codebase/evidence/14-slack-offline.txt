▶ timeout
    attempt 1: hard failure (slack timeout: no response) → not retryable
    Slack undeliverable → routing to the ticket fallback (escalation is never lost)
    attempt 1: hard failure (slack timeout: no response) → not retryable
    circuit-breaker TRIPPED after 2 consecutive failures — further calls short-circuit to the fallback
    Slack undeliverable → routing to the ticket fallback (escalation is never lost)
    circuit-breaker OPEN → skipping Slack, routing to the ticket fallback
  PROBLEM: timeout (Slack hangs, ×3)  →  HANDLED: breaker opened after 2 fails; 3rd call short-circuited → reason=circuit_open

▶ duplicate
    idempotency: key 'dup-1' already sent → returning prior result, not re-posting
  PROBLEM: duplicate (same idempotency key twice)  →  HANDLED: second send deduped=True — on-call paged once, not twice

  PROBLEM: schema_drift (200 but response shape changed)  →  HANDLED: defensive parse → still delivered_via=slack, flagged not crashed
